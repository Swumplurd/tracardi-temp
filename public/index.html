Ejemplo Frontend Vanilla JS (ejemplos/vanilla-js-snippet.html) 
async function sendEvent(eventType, properties = {}) {
  const payload = {
    source: { id: "demo-source" },
    session: { id: localStorage.getItem("session_id") || "sess_001" },
    events: [
      {
        type: eventType,
        properties: properties
      }
    ]
  };

  const res = await fetch("http://localhost:8686/track", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload)
  });
  
  return await res.json();
}
Hook de React (ejemplos/react-integration.jsx) 
import { useCallback, useState } from 'react';

export function useTracardi(sourceId = 'demo-source') {
  const [sessionId] = useState(() => 'sess-' + Math.random().toString(36).substr(2, 9));

  const track = useCallback(async (eventType, properties = {}) => {
    const response = await fetch('http://localhost:8686/track', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        source: { id: sourceId },
        session: { id: sessionId },
        events: [{ type: eventType, properties }]
      })
    });
    return response.json();
  }, [sourceId, sessionId]);

  return { track, sessionId };
}
Backend Node.js (ejemplos/node-backend-tracking.js) 
const http = require('http');

async function trackEvent(eventType, properties = {}) {
  const payload = JSON.stringify({
    source: { id: 'demo-source' },
    session: { id: `backend-sess-${Date.now()}` },
    events: [{ type: eventType, properties }]
  });

  // Enviar a Tracardi API (http://localhost:8686/track)
  return fetch('http://localhost:8686/track', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: payload
  }).then(r => r.json());
}
Backend Python (ejemplos/python-backend-tracking.py) 
import requests

def send_tracardi_event(event_type, properties):
    url = "http://localhost:8686/track"
    payload = {
        "source": {"id": "demo-source"},
        "session": {"id": "python-session-001"},
        "events": [
            {
                "type": event_type,
                "properties": properties
            }
        ]
    }
    response = requests.post(url, json=payload)
    return response.json()

💡 Conceptos Clave para Entender y Usar Tracardi

🔌

1. Event Source (Fuente)

Representa el origen de los datos (tu sitio web, app móvil, webhook de Stripe o API backend). Cada fuente tiene un ID único (ej: demo-source).

👤

2. Profile (Perfil de Cliente)

Es la identidad unificada del usuario. Tracardi fusiona automáticamente eventos anónimos y conocidos pertenecientes a la misma persona.

⏱️

3. Session (Sesión)

Agrupa eventos continuos realizados por un usuario en un intervalo de tiempo (similar a las sesiones de navegación web).

⚡

4. Event (Evento)

Cualquier acción de interés: page-view, add-to-cart, purchase, lead-signup. Lleva metadatos y propiedades personalizadas.

🔀

5. Flow / Workflow (Flujo de Trabajo)

En el Dashboard (8787), puedes crear flujos visuales que reaccionan a eventos: segmentar usuarios, enviar correos, enriquecer datos o llamar APIs.

🎯

6. Rule (Regla)

Conecta un Event Source y un tipo de Evento con un Workflow en Tracardi.
